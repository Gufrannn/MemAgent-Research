# COSI standalone decision: MERGE / NO-GO

The route is closed before H20 training. This is a scientific decision, not an infrastructure failure.

Independent review found that the defensible acceptance estimand must be a fresh-root, full O-versus-N trajectory contrast. The cached 2x2 writer/continuation design is only a boundary-local path-specific diagnostic. Repeatedly reusing a small held-out transport set would overfit the acceptance oracle, so the corrected protocol assigned disjoint roots to 25 updates and two attempts per update with family-wise error 0.05.

That correction makes the proposed online certificate incompatible with the frozen compute contract. For return differences in [-1,1], per-attempt alpha 0.001 and 32 roots, the Hoeffding half-width is about 0.657. A 0.05 half-width requires 5,527 independent roots per attempt. This exceeds the route's 3x Original compute ceiling and would make the preregistered 20--80% T5 acceptance rate implausible. A looser heuristic would no longer support the paper's certificate claim.

The four-cell crossed replay may still be useful as a mechanism diagnostic in a broader recurrent-policy-optimization paper, but only if E1 shows single-update residuals and genuine reversals beyond KL/sequence diagnostics. Anchor gaps of five updates are mechanism screening only and cannot authorize an online update rule. No Original checkpoint is rerun, no Method T5 is launched, and no H20 result is claimed.

The branch retains: the paper frame and claim matrix; an exact GRPO-style toy reversal; authenticated four-cell validation; root-clustered statistics; baseline import; E1 audit scaffolding; append-only ledgers; checkpoint hashing; dynamic-GPU preflight and locks; and read-only audit. Its T5/continuation preflight fails closed by design.
