# Shape A deterministic-feature data-processing firewall

If a baseline contains the complete audit transcript and metadata `(R,M)` and `D*=f(R,M)`, then `D*` cannot add information conditional on `(R,M)`. Any finite-model improvement is only sample-efficient structural inductive bias. The frozen central wording is: “preregistered relational compression of the same audit transcript predicts commit-vs-discard effect beyond frozen direction-blind marginal summaries and matched pairing shams.”

Before outcomes, `D_input_provenance.json` records D-dependent cells, roles, targets, masks, normalization, fields retained/discarded by the baseline, deterministic reconstructability, access tiers, and real query/token/GPU budgets. Unknown provenance and access mismatch are No-Go. Automatic semantics are `M_RELATIONAL_COMPRESSION`, `F_DETERMINISTIC_INDUCTIVE_BIAS`, `A_ACCESS_MISMATCH_NO_GO`, and `UNKNOWN_PROVENANCE_NO_GO`.

Residual variance ratio, condition number, VIF, and role overlap relative to P2 marginal summaries are outcome-free model-class/representation audits, not mutual information. CPU-only sensitivities are a frozen full-transcript random projection and matched pairing sham. If existing outputs are insufficient, report `not_available_existing_outputs_insufficient`; never add rollout to fill the gap.
