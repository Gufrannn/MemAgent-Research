# Current ranked research decision: OOTT addendum

The 7B execution ranking is unchanged. `qa_only_original` remains independently runnable; NCR remains the sole narrowly conditional method candidate under the existing evidence ledger. OOTT is a zero-GPU post-hoc analysis family and never enters the training candidate set.

Within OOTT, O3a uses only P-class pre-policy/pre-outcome frozen strata. O3b uses only O-class policy-induced occupancy descriptors for common-support, coverage, and descriptive transport maps while retaining the total unstratified contrast. Y-class final-answer/gold/reward strata are RED calibration/error-analysis inputs, not occupancy localization. Every stratum manifest must pass the timing validator before results are read.

HiMPO directly covers local updated-vs-previous memory target-answerability credit, target-conditioned hindsight blame filtering, and memory-token-only local advantage. These are permanent T1 novelty collisions. Any T1 NCR/local-credit proposal equivalent to that recipe is `NO_METHOD`. Shape A remains T0 outcome-independent pre-candidate measurement/effect-modification work: it cannot read candidate text, materialized `m_t`, or new-vs-old utility, and HiMPO is not a T0 baseline. A future unique T1 candidate would require a fully information/compute-matched HiMPO-like baseline, but no such baseline is currently authorized for implementation or training.

Memory-R2 directly covers unfair global GRPO comparisons after memory-state divergence, same-anchor session-local rerollout, combined global/local group-relative objectives, and 8→16→32 curricula. Generic blocked within-state grouping, local rerollout, CERC/curriculum as a method are permanent No-Go titles. Its rerollouts regenerate extractor candidates and manager actions, so it does not identify the exact same-materialized-candidate commit-versus-discard effect retained by Shape A. No LoGo-GRPO implementation or long training is currently authorized.

Replay estimands are now mechanically separated. P fixes only the pre-session anchor and labels same-anchor policy-relative credit; H is the teacher-forced updated-versus-old target-answerability privileged proxy; E alone fixes the upstream state and one materialized candidate and changes only commit versus retain under a shared suffix endpoint. P is not E, H is not E, and one candidate's E contrast is not state-level writer-policy risk. Only exact-NOOP v2 eight-key joins qualify; legacy replay is excluded.
