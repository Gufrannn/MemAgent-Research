# Objective–Occupancy Transport Triangulation: 7B integration note

The 7B suite adopts the P/O/Y timing firewall. O3a is restricted to P-layer frozen pre-policy strata. O3b is restricted to O-layer policy-induced occupancy support maps and must report cell probabilities, common support, coverage shift, and the unstratified total contrast with descriptive—not causal—wording. Y-layer endpoint-defined cells are routed to RED calibration only. The validator must pass before any stratum analysis; OOTT remains zero-GPU and cannot unlock training.

O2 stochastic T25↔T200 transport is currently unauthorized. Any future gated run must first pass the checkpoint seed-coupling firewall: independent non-overlapping checkpoint namespaces are primary, four seeds are averaged within checkpoint before example-level contrast, and stable example remains the independent unit. Same-seed CRN is implementation-coupling sensitivity only under corrected trajectory seeds, BCI coupled qualification, and a disjoint prefrozen namespace. Direction disagreement is `COUPLING_SENSITIVE_STOCHASTIC_TRANSPORT`, not a basis to select the preferred coupling.
