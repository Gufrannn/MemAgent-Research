# Closed-loop resource-mode contract v8

The terminal GC/GF/GN/GS intersection-union test identifies raw QA under the frozen protocol. It does not by itself establish equal-budget, utility, or cost advantage. The primary resource mode is frozen before outcomes.

Mode A is accuracy-first. Raw Y is retained and each policy × example records cumulative calls, input/generated/context tokens, wall time, fallback use, certificate/readout calls, and policy-induced memory tokens. Incomplete cost qualification appends `WITH_COST_UNQUALIFIED` but does not delete the raw-QA IUT. Writer-proposal call parity for GF/GN does not cover GC certificate/readout calls or policy-induced memory length. A practical certificate-mechanism claim additionally requires a content/random/sham certificate control with the same call and token envelope.

Mode B freezes one common resource vector and its over-budget truncation, skip, and fallback rules. Every assigned example remains in the value; over-budget rows may not be deleted. Failure yields `FIXED_BUDGET_POLICY_VALUE_INVALID`, while any raw outcomes are labeled unconstrained description only.

Utility `U=Y-lambda*C` requires lambda and cost normalization from a pre-outcome use case. Post-outcome lambda sweeps and gain-per-token-only reporting are forbidden. The exact counterexample has GC raw QA .70 at cost 2 and control .68 at cost 0: raw gain is .02, but at lambda .02 GC utility is .66 versus .68, and GC is infeasible at fixed budget 1.
