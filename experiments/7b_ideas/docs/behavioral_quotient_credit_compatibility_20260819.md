# Behavioral-Quotient Credit Compatibility

BQCC requires both low reward split inside invariant controlled pairs and frozen-direction reward separation across necessary target-changing pairs. Either axis may fail independently; the Credit Funnel is not assumed to be a nested quotient chain.

For one uid, GRPO `A=(R-b)/s`, `s>0`, gives `Delta A=Delta R/s`. A common baseline and standard deviation therefore cannot repair a necessary reward tie or remove an invariant nuisance split. Absolute advantage sign is reference-set dependent: focal rewards .6/.5 are both positive beside .0/.0 and both negative beside 1/1. Centering a blocked pair whose difference is invariant nuisance forces that erroneous contrast rather than fixing it.

The analyzer requires exactly three inputs: `PAIRS.jsonl`, the complete `TARGET_LEDGER.jsonl`, and the outcome-pre-frozen `MANIFEST.json`. It hard-checks all canonical SHA values and exact target→admitted→analyzed key closure. Any infrastructure failure blocks a point verdict. Coverage sufficient to run is not population identification: below 100% I/N pair or example coverage, scope stays `admitted_relation_stratum_only` unless a separately frozen and validated missingness/partial-ID model exists.

The CPU audit reports stable-example-clustered `InvariantSplitMass`, `NecessaryTieMass`, `NecessaryWrongMass`, and discovery-frozen context sign flips. `actual Delta A=Delta R/s` is checked by maximum pair error before any pair-to-example averaging. Pairs and paths do not increase independent n. Each defect axis uses its 95% example-cluster bootstrap interval: upper bound at or below the frozen threshold is `LOW_CERTIFIED`, lower bound above it is `HIGH_ESTABLISHED`, and a crossing interval is `THRESHOLD_UNCERTAIN`. Any uncertain axis yields `BQCC_INCONCLUSIVE_THRESHOLD_UNCERTAINTY`; it may deny compatibility but cannot name nuisance specificity, reward aliasing, or partition crossing. The only compatible success label is `FINITE_QUOTIENT_COMPATIBLE`.

BQCC is the unique prioritized RL bridge only after Shape A passes. It is not a second contribution and never authorizes training or new rollout. It adjudicates scalar quotient compatibility only; gradient delivery remains the existing `G_credit→G_task→G_total→Delta_theta_actual`/CSFGW-W4 problem.
